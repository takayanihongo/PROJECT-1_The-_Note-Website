Closures dan Lexical Scope

JavaScript closure scope function · Diperbarui 2 jam lalu

Closure adalah salah satu konsep yang sering bikin bingung di awal, tapi sebenarnya cuma satu ide sederhana: fungsi mengingat lingkungan tempat ia dibuat, bukan tempat ia dipanggil.

Apa itu Lexical Scope

Lexical scope berarti scope sebuah variabel ditentukan oleh di mana kode itu ditulis, bukan dari mana fungsi itu dipanggil. Ketika sebuah fungsi didefinisikan di dalam fungsi lain, ia otomatis punya akses ke variabel di fungsi luar tersebut.

Bayangkan lexical scope seperti alamat rumah: begitu kamu lahir di suatu alamat, alamat itu melekat padamu ke mana pun kamu pergi — bukan berubah tergantung siapa yang mengunjungimu.

Contoh Closure Sederhana

Perhatikan contoh berikut. Fungsi increment tetap bisa mengakses variabel count meskipun buatCounter sudah selesai dijalankan:

javascript 
function buatCounter() {
  let count = 0;

  return function increment() {
    count += 1;
    return count;
  };
}

const counterA = buatCounter();
console.log(counterA()); // 1
console.log(counterA()); // 2

const counterB = buatCounter();
console.log(counterB()); // 1, tidak terpengaruh counterA

Setiap kali buatCounter() dipanggil, JavaScript membuat scope baru dengan count miliknya sendiri. Fungsi increment yang dikembalikan "membawa" scope itu ke mana pun ia dipakai — inilah closure.

Kenapa Ini Penting di Dunia Kerja

Closure dipakai di mana-mana tanpa kamu sadari:

  • Membuat data privat sebelum class dan #field populer.
  • Event handler yang perlu mengingat state tertentu, misalnya ID item yang diklik.
  • Custom hook di React seperti useState, yang bergantung pada closure untuk menyimpan nilai antar render.
  • Memoization dan caching sederhana di sisi server maupun client.

Kesalahan Umum

Kesalahan paling klasik adalah memakai closure di dalam loop dengan var, sehingga semua fungsi berbagi satu variabel yang sama alih-alih punya salinan masing-masing. Mengganti var dengan let biasanya cukup untuk memperbaikinya, karena let membuat binding baru di setiap iterasi.
